# ヒーローズ・オブ・マイト・アンド・マジック シリーズ 日本語化プロジェクト

ヒーローズ・オブ・マイト・アンド・マジック（Heroes of Might and Magic）シリーズを日本語で遊べるようにする、非公式のファンメイド日本語化プロジェクトです。
GOG.com で販売されている版を対象にしています。
開発元・販売元とは関係ありません。

- サイト（作品の紹介・入れ方）: https://higesho.github.io/homm-ja/
- ダウンロード: [リリース](https://github.com/higesho/homm-ja/releases)
- マイト・アンド・マジック シリーズの日本語化: https://higesho.github.io/mm-ja/
- ウルティマ シリーズの日本語化: https://higesho.github.io/ultima-ja/
- D&D シリーズの日本語化: https://higesho.github.io/dnd-ja/
